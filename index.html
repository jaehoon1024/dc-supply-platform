용어 · 기준

수전용량
한전에서 받는 전력(계약·수전 기준, MW). 냉각·손실을 포함한 시설 전체 기준입니다.
IT Load
서버·네트워크 장비에 공급 가능한 전력(MW). 보도의 "○○MW급"은 단위가 불명확하면 IT Load 칸에 추정으로 넣고 비고에 "단위 미상"을 적습니다.
자체 / 상용
자체: 사업자가 자기 서비스용으로 짓고 운영(공공 포함). 상용: 코로케이션·임대·하이퍼스케일 임대.
운영 / 개발
상태가 운영중이면 운영, 나머지는 개발. 상태에서 자동으로 정해집니다.
RFS
Ready for Service. 고객이 실제로 쓸 수 있게 된 시점입니다. 공급 추이는 RFS(없으면 준공월) 연도로 집계합니다.

준비단계 (설계중 센터)

단계상태값완료 기준자동 반영
① 부지확보미확보 · 협상중 · 확보매입·임차 계약, 산단 분양계약, 부지 확보 공시·보도건축허가가 확인되면 '확보(추정)'
② 전기확보미확보 · 협의중 · 확보한전 전기사용계약·계통연계 승인, 수전 MW 확보 보도—
③ 건축허가미신청 · 심의중 · 허가건축허가일(건축HUB) 또는 지자체 발표건축HUB 허가일 → '허가(확정)' + 허가월
→ 착공착공 이후 센터는 저장값이 없으면 세 단계 모두 완료로 간주합니다. 설계중 센터의 실현확률: 부지확보 단계 30% · 전기확보 단계 45% · 건축허가 단계 60% · 착공 대기 70% (미분류는 50%).

주소 정합성

  1. 시·도 표기 정규화(17개 시도)
  2. 시·군·구 확인 → 없으면 주소불완전
  3. 지번·도로명 번호 → 없으면 부분
  4. 입력 시도와 주소 시도 비교 → 다르면 불일치
  5. 좌표가 시도 범위 안인지 → 밖이면 불일치, 없으면 좌표없음
